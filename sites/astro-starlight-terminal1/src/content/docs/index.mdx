<div class="home-prose">
<p>The <strong>shll toolkit</strong> is seven small CLIs for AI-assisted coding — independent, brew-installable tools that each do one job well and compose into a single workflow. Together they run the whole loop: from capturing an idea to a merged pull request, with the AI doing the typing and a plan in place before it starts.</p>
<p>Built for developers running multiple coding agents in parallel: every backlog, plan, and cost report is a plain file you can <code>cat</code>, <code>grep</code>, and <code>git diff</code> — the contract lives in the file, not in hidden state. No SDK, no vendor lock-in, nothing hidden from <code>git</code>.</p>
</div>
</section>

<div class="home-prose not-content">
<p>One idea fans out into parallel agents — each in its own isolated working copy — and converges back into a single dashboard. Inside the loop, <a href="/tools/idea/overview/">idea</a> captures the backlog, <a href="/tools/fab-kit/overview/">fab-kit</a> turns an item into a plan, <a href="/tools/wt/overview/">wt</a> gives each change a disposable worktree, and <a href="/tools/run-kit/overview/">run-kit</a> watches every session. Around the loop, <a href="/tools/hop/overview/">hop</a> jumps between repos, <a href="/tools/tu/overview/">tu</a> tracks what it all costs, and <a href="/tools/shll/overview/">shll</a> keeps the toolkit installed.</p>
</div>
