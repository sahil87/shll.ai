`tu` is a token and cost tracker for AI coding sessions — it tells you what Claude Code, Codex, and OpenCode are actually costing you, across every tool and every machine you work on. It syncs usage between machines and has a live watch mode for keeping the running total in a side pane while you work. If you're spending real money on coding agents, `tu` is how you see where it goes.

## How it fits

`tu` is the cost overlay on the whole loop: run it alongside a **[fab-kit](/fab-kit/)** pipeline to watch what a change costs end-to-end, or keep it in view next to the **[run-kit](/run-kit/)** dashboard while a fan-out of agents runs.
