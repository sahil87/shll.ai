Constraints: vanilla JS only, zero new dependencies (Constitution VI — do NOT pull in xterm.js or a completion lib); preserve the existing paste-normalization and focus/blur cursor-blink behavior; respect `prefers-reduced-motion` if any animation is added; keep dark/light parity (reuse `--c-*` vars, no new hardcoded colors). The interactive prompt currently lives only on the homepage (`src/content/docs/index.mdx`). Acceptance: ↑/↓ recall prior commands; Tab completes `in`→`install` and `cd h`→`cd hop`; ambiguous Tab lists candidates; Ctrl-L clears; Ctrl-C cancels the line.
